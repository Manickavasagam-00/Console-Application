# Travel Budget Planner
## Overview
Travel Budget Planner is a Java console application that helps users create and manage travel plans. Users can store travel details such as destination, number of days, and total budget. The application automatically calculates the estimated expenses for travel, hotel, food, and miscellaneous costs based on the entered budget.
The project is developed using Object-Oriented Programming (OOP) concepts such as **Encapsulation** and **ArrayList**.

---

## Features

* Create a new travel plan
* View all travel plans
* Update existing travel plans
* Delete travel plans
* Automatic budget allocation:

  * Travel – 25%
  * Hotel – 40%
  * Food – 25%
  * Miscellaneous – 10%
* Dynamic data storage using ArrayList
* Encapsulation using private variables, getters, and setters
* Menu-driven console interface

## How to Run

1. Download or clone the repository.
2. Open the project in VS Code, IntelliJ IDEA, or Eclipse.
3. Compile the program:

   ```
   javac TravelBudgetPlanner.java
   ```
4. Run the program:

   ```
   java TravelBudgetPlanner
   ```
